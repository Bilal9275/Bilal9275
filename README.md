## 👨‍💻 About Me

I'm a blockchain developer focused on **smart contracts** and the **Web3** stack built around them. Over **3+ years** I've shipped the on-chain logic behind DeFi protocols, NFT marketplaces, presales, staking systems and token economies. A lot of that work is running **live in production** across multiple chains.

I don't stop at the contract. I also handle **Web3 frontend integration** and build the **Node.js / Express / MongoDB** APIs and deployments that turn a contract into a working product.

- ⛓️ Comfortable on **any EVM chain** (Ethereum, BNB Chain, Arbitrum, Base, Polygon and more), plus **Solana**
- 🔐 Strong on contract security patterns like reentrancy guards, anti-bot, and emergency pause/recovery
- ☁️ Ship and deploy on **AWS EC2, Vercel, Heroku and Netlify**
- 🤖 Currently leveling up in **Python and AI agents** for autonomous on-chain tooling
- 💼 **Available for contract-based and project-based work.** Let's build something.
